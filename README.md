# My DashboardKDV 2.3.1

**My DashboardKDV** — персональная веб-панель для быстрого запуска и организации приложений и сервисов.

## Возможности

- 📱 Приложения: добавление, редактирование, удаление, избранное и поиск.
- 🗂️ Категории: создание, изменение и удаление.
- 🖱️ Drag & Drop: изменение порядка приложений с сохранением.
- 📐 8 вариантов размеров плитки для каждого приложения:
  - Мини — 1×1
  - Маленькая — 1×1
  - Обычная — 1×1
  - Широкая — 2×1
  - Высокая — 1×2
  - Большая — 2×2
  - XL — 3×2
  - Герой — 3×1
- 😀 Emoji, локальные изображения, URL-иконки и favicon.
- ☀️ Светлая и 🌙 тёмная тема.
- 🖼️ Пользовательский фон с затемнением и размытием.
- 📺 Интеграция с Emby.
- 💾 Экспорт и импорт настроек.
- 🐳 Docker / Docker Compose.

## Быстрый запуск

Требования: Docker и Docker Compose.

```bash
git clone https://github.com/Podpeedami/My-DashboardKDV.git
cd My-DashboardKDV
docker compose pull
docker compose up -d
```

Открыть: http://localhost:8080

Проверка контейнера:

```bash
docker ps
```

## Docker image

```text
ghcr.io/podpeedami/my-dashboardkdv:latest
```

## Данные

Пользовательские данные находятся в `data/`:

```text
data/
├── dashboard.db
├── icons/
└── backgrounds/
```

Каталог `data` подключён как volume и не должен удаляться при обновлении контейнера.

## Обновление

```bash
docker compose pull
docker compose down
docker compose up -d
```

Если браузер показывает старую версию интерфейса, выполните `Ctrl + F5`.

## Локальная разработка

Для сборки из исходников используется: `docker compose.build.yml` (если файл доступен в текущем репозитории).

Пример:

```bash
docker compose -f docker-compose.build.yml up --build -d
```

## Резервная копия

В настройках Dashboard доступны экспорт и импорт. Также рекомендуется перед обновлениями сохранять каталог `data/`.

## Режим редактирования панели

Кнопка **✏️ Редактировать** включает редактор макета. В этом режиме можно перетаскивать приложения и категории, менять размер плитки кнопкой **📐**, дублировать приложение и отменять незавершённые изменения. Для применения порядка и изменений размера нажмите **💾 Сохранить макет**.


## Индивидуальное оформление плиток

Каждое приложение может иметь собственный фон, цвет или изображение, прозрачность, размытие, размер иконки, размер названия, а также отдельное отображение описания и URL. Настройки сохраняются отдельно для каждой плитки и входят в экспорт/импорт.
