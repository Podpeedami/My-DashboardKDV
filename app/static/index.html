🎨 Тема

Фон не установлен

✨ Внешний вид панели

Параметры применяются сразу и сохраняются отдельно от самого изображения.

🔎 Локальные сервисы в сети

Однократный поиск распространённых веб-сервисов по всем адресам указанной приватной IPv4-сети. Ничего автоматически не добавляется и постоянного мониторинга нет.
Dashboard подставит сеть автоматически, если открыт по локальному IPv4-адресу. Например, для 192.168.1.115 будет предложено 192.168.1.0/24.

📺 Emby

⚠ Импорт заменит текущие приложения и категории данными из файла. API ключ Emby намеренно не экспортируется.
